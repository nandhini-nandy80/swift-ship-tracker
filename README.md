# Swift Ship Track

A simple, responsive web application for tracking courier shipments in real time. Customers can enter a tracking ID to see the current status of their parcel, and admins can create shipments and update their progress.

Developed as part of the **Naan Mudhalvan** programme.

## Features

- Track a parcel using its tracking ID
- Visual route progress bar and status timeline
- Five delivery stages: Booked, Picked up, In transit, Out for delivery, Delivered
- Admin panel to create new shipments
- Admin status updates with automatic timestamped entries
- Data saved in the browser (localStorage)
- Responsive layout with light and dark mode support

## Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla)

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.

No installation or server is required.

## Sample Tracking IDs

| SST1002 | Madurai to Chennai | Delivered |
